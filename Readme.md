# Self-assessment

A self-assessment of how inclusive your own digital service is. It reuses the architecture of the
Quiz, with the same answer scale for every question.

Part of [PAi13](https://github.com/foucblg/PAi13), a serious game on inclusive digital services built
with the Lyon metropolitan area. Live demo: [foucblg.github.io/Auto-evaluation](https://foucblg.github.io/Auto-evaluation/).

Technical documentation: [documentation.md](documentation.md).

## Run locally

```bash
npm install
npx ng serve   # http://localhost:4200/
```

Stack: Angular 18, TypeScript.
